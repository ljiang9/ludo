# Ludo 飞行棋

2~4 人对战的经典飞行棋,纯 Python 标准库实现,无第三方依赖。

## 玩法

- 52 格主赛道,每人 4 枚棋子,掷出 **6 点**才能从大本营出发。
- 落到对手棋子所在格则**吃掉**对方(送回大本营);8 个**安全格**(4 起点 + 4 星形格)不可被吃。
- 走完主赛道进入 5 格终点道,**需精确点数**到达终点。
- 掷出 6 / 吃子 / 棋子到家均可**再掷一次**;连续三次掷出 6 则本轮作废。
- 4 枚棋子**全部到家**者获胜。

## 用法

```bash
# 人机交互(2 人)
python3 -m ludo
# 4 人交互
python3 -m ludo --players 4
# AI 对 AI 自动演示 10 局
python3 -m ludo --auto --games 10 --seed 42
```

交互时按回车掷骰,从可走棋子下标中选一枚(直接回车用 AI 推荐)。

## AI 说明

贪心策略:吃子 > 到家 > 出营 > 推进进度 > 避险(不落在 1~6 格内有对手棋子的非安全格)。
平局时随机打破,可复现(`--seed`)。

## 诚实局限

- AI 只是 1 步贪心,不做深层搜索;熟悉规则的人类通常能赢。
- 未实现"双子成垒不可过/不可吃"规则;叠子仅按普通吃子处理。
- 文本界面,无图形/动画/存档/悔棋;Python 3.10+,纯标准库。
